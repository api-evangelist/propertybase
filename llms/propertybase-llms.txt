# Propertybase

> Propertybase (by Lone Wolf) is a Salesforce-native real estate CRM used by 20,000+ users across 60+ countries to manage leads, listings, contacts, transactions, and marketing. The Propertybase GO API (now part of Lone Wolf Front Office / the Lone Wolf Foundation cloud) is a JSON REST API for reading and writing CRM records.

This llms.txt was generated by the API Evangelist enrichment pipeline from apis.yml and the repository artifacts on 2026-07-20. It is not published by Propertybase.

## API

- [Propertybase GO API Reference](https://apidocs.propertybase.com/): JSON REST API. Resources include Offices, Agents, Employees, Teams, Leads, Tasks, Events, Messages, Properties, Showings, Saved Searches, Market Reports, Developments, Dynamic Forms, Contact Forms, Property Views, and Favorites. Methods: GET, POST, PATCH/PUT, DELETE. URI-path versioning at /api/v2/.
- Authentication: static API key in the `X-BL-API-Key` header, issued by Propertybase support; per-resource Read/Write/Delete permissions.
- Response envelope: JSON object with `status` (success/failure/unauthorized), `message`, and either `data` or an `errors[]` array.
- Base URL is per-account (the API domain is provided by Propertybase support).
